# 💅 Agenda do Salão

Projeto de estudo desenvolvido para praticar desenvolvimento web utilizando HTML, CSS e JavaScript.

## 📋 Sobre o projeto

O Agenda do Salão é um sistema de agendamento desenvolvido como projeto prático de estudos.

A aplicação permite selecionar um serviço, escolher um profissional, informar uma data e selecionar um horário para o atendimento.

## 🚀 Funcionalidades

- Seleção de serviço
- Seleção de profissional
- Escolha da data
- Escolha do horário
- Validação das informações
- Controle de horários disponíveis

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Este projeto foi criado com o objetivo de praticar e desenvolver conhecimentos em:

- Estruturação de páginas com HTML
- Estilização e responsividade com CSS
- Lógica de programação com JavaScript
- Manipulação do DOM
- Criação de interfaces interativas
